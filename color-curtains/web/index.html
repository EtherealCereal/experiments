The canvas is painted white once in setup(). Each call to draw() adds five shapes without clearing earlier ones. At 10 frames per second, that is about 50 new squares per second.

w = (x + y) / 5.0 makes squares larger farther toward the bottom-right. Red depends on x, green on y, and blue stays between 20 and 30. random(30) gives each square less than 12% opacity.

Nothing actually moves or fades away: later translucent squares cover earlier colors. Each overlap blends the new color with the existing image. Our adaptation keeps that accumulation, but uses tall rectangles, independently adjustable widths, and the video's cooler palette.

void setup() {
size(displayHeight, displayWidth);
background(255);
frameRate(10);
}
void draw() {
int numrects = 5;
float maxalpha = 30;

for (int i=0; i<numrects; i++) {
 float x = random(width);
 float y = random(height);
 float w = (x + y) / 5.0;
 float h = w;
 
 float r = x / 3.0;
 float g = y /4.0;
 float b = random(20, 30);
 float a = random(maxalpha);
 
 fill(r, g, b, a);
 noStroke();
 //strokeWeight(5);
 rect(x, y, w, h);
}
}
